# Overview

<figure><img src=".gitbook/assets/nationalism-scene.png" alt=""><figcaption></figcaption></figure>

This analysis explores the ideas behind nationalism. Three distinct types of nationalism are identified and compared including - civic, cultural and ancestral nationalism. Each form of nationalism can have some differences in how it defines national membership and preserves continuity as well as how it handles migration, citizenship, demographics and self-determination.

Different nationalist models can suit different societies. This will be influenced by whether they prioritise political inclusion, cultural preservation or ancestral continuity. Different types of nationalism can also be adopted in a number of ways, a nation-state does not need to adopt just one solution. These alternative approaches are covered in this resource.
